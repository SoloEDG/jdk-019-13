# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 钢笔工具

- **点击 / 短拖**：逐个放置贝塞尔节点（短拖可拉出该节点的控制手柄），连续点击追加到同一条路径，Enter 或双击完成。
- **按住拖出**：进入自由笔迹模式，指针离开画板也会持续以文档坐标采样；松手后弹出预览面板，显示节点数量与拟合误差（RMSE / 最大偏差，均为文档单位，缩放不改变拟合形状），可拖动“平滑程度”滑块实时重新拟合后再确认或取消。
- 拟合优先抑制手抖，同时保留刻意画出的尖角（尖角节点手柄长度为 0）。
- 出界或快速跳跃会自动断成多段，两段笔迹不会被连接；确认后每段成为独立路径，沿用钢笔默认颜色与描边，可继续用节点工具编辑。
- 取消只移除本次预览且不产生撤销记录；保存与 SVG 导出只包含已确认的曲线。

## 测试

- `npm test`：拟合与笔迹分段的纯逻辑单元测试（esbuild 打包后由 Node 内置测试运行器执行）。
- `npx playwright test`：浏览器端到端测试（首次运行需 `npx playwright install chromium`）。
